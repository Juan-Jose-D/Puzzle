# 🧩 Puzzle

Este es un proyecto sencillo de un juego tipo puzzle creado en Java usando BlueJ, un IDE educativo muy útil para aprender programación orientada a objetos (POO).

## 🎯 Objetivos de aprendizaje
Este proyecto fue creado como ejercicio para:

- Practicar el diseño con clases
- Entender cómo interactúan los objetos
- Familiarizarse con un entorno de desarrollo para principiantes (BlueJ)



## 📚 Sobre el proyecto

El objetivo de este proyecto es ayudar a comprender los conceptos fundamentales de la POO en Java, como:

-Clases y objetos
-Encapsulamiento
-Interacción entre métodos
-Lógica y condicionales básicas

El juego simula una lógica de puzzle simple, donde el usuario interactúa con piezas o elementos que deben ser ordenados, movidos o combinados (dependiendo de cómo lo hayas implementado).
